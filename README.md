## Setup

### Dependencies

Download these before running the project.

* [uv](https://docs.astral.sh/uv/)
* [yarn](https://yarnpkg.com/)

### Backend

There is a docker compose file including the backend, minio, keycloak, notification api and the database.

Just run:

```bash
# Run this in project root
docker compose up --build
```

The backend is setup so that simple changes will be loaded immediately with hot reload but for some complex stuff the container must be restarted.

When the backend is up, you can go to http://localhost:8000/docs and see the autogenerated openapi docs.

**Services:**
- Backend API: http://localhost:8000
- API Documentation: http://localhost:8000/docs
- Minio (S3): http://localhost:9000
- Keycloak (Auth): http://localhost:8080
- Database: localhost:5432

### Frontend

```bash
# Runs code orval and grpc code generation for the frontend
make generate

# Starts the frontend
cd frontend
yarn dev
```

Then go to http://localhost:3000 to access the frontend.

## Database Migrations

The backend uses Alembic for database migrations. When you start the backend with Docker, migrations are automatically applied.

To create a new migration after model changes:

```bash
# Inside the backend container or with proper environment
alembic revision --autogenerate -m "description of migration"
```

To apply pending migrations:

```bash
alembic upgrade head
```

To revert to a previous migration:

```bash
alembic downgrade -1
```

## Important Bits

Backend and frontend are both formatted. Use black formatted for the backend python code and prettier for the frontend typescript code.

Make sure that fastapi routes are types properly and named properly, otherwise orval can't properly generate the files.

For translation we use i18next and save the translations as json. Don't write any text in typescript, otherwise it won't be translated.
